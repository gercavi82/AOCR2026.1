## 1. Pruebas de Base de Datos

### 1.1 Verificar Tablas Creadas
```sql
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public' 
AND table_name LIKE 'aocr%'
ORDER BY table_name;
```
**Resultado esperado:** Debe incluir `aocr_tbhistorialestado`

- [ ] ✓ Tabla existe
- [ ] ✓ Tiene 7 columnas (id, codigo_solicitud, estado_anterior, estado_nuevo, fecha_cambio, codigo_usuario, observaciones)

### 1.2 Verificar Columnas en aocr_or_orden
```sql
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'aocr_or_orden'
ORDER BY ordinal_position;
```
**Resultado esperado:** Solo 8 columnas (NO debe incluir observacion, subtotal, admin, etc.)

- [ ] ✓ Columnas coinciden con schema
- [ ] ✓ Tipos de datos correctos

## 3. Pruebas Funcionales - Solicitudes AOCR

### 3.1 Crear Nueva Solicitud
1. Login con usuario válido
2. Navegar a `/SolicitudAOCR?abrir=nueva`
3. Completar formulario:
   - Nombre Operador: "Aerolíneas Test S.A."
   - RUC: "1234567890001"
   - Email: "test@aerolinea.com"
   - Tipo Operación: "135"

**Resultado esperado:**
- [ ] ✓ Formulario carga sin error 42P01
- [ ] ✓ No aparece "Unexpected token '}'"
- [ ] ✓ JavaScript ejecuta correctamente

### 3.2 Guardar Solicitud
1. Hacer clic en "Guardar Borrador"
2. Verificar en BD:
```sql
SELECT * FROM aocr_tbsolicitud 
WHERE nombre_operador = 'Aerolíneas Test S.A.';
```

**Resultado esperado:**
- [ ] ✓ Registro insertado con estado "Borrador"
- [ ] ✓ `codigo_solicitud` generado (SERIAL)
- [ ] ✓ `codigo_usuario` es INTEGER (no NULL ni string)

### 3.3 Historial de Estados
1. Cambiar estado de solicitud a "En Revisión"
2. Verificar en BD:
```sql
SELECT * FROM aocr_tbhistorialestado 
WHERE codigo_solicitud = [ID_SOLICITUD];
```

**Resultado esperado:**
- [ ] ✓ Registro de cambio de estado insertado
- [ ] ✓ `estado_anterior` = "Borrador"
- [ ] ✓ `estado_nuevo` = "En Revisión"
- [ ] ✓ `fecha_cambio` es timestamp actual

## 4. Pruebas Funcionales - Órdenes de Recaudación

### 4.1 Crear Nueva Orden
1. Navegar a `/OrdenRecaudacion/Nueva`
2. Seleccionar solicitud existente
3. Agregar conceptos:
   - Concepto: "Tasa de Inspección"
   - Cantidad: 1
   - Valor Unitario: 150.00

**Resultado esperado:**
- [ ] ✓ Vista carga correctamente
- [ ] ✓ No hay error 404 (ruta existe)
- [ ] ✓ JavaScript de detalles funciona

### 4.2 Guardar Orden
1. Hacer clic en "Generar Orden"
2. Verificar en BD:
```sql
SELECT o.*, od.* 
FROM aocr_or_orden o
LEFT JOIN aocr_or_orden_detalle od ON od.orden_id = o.id
WHERE o.numero_orden = '[NUMERO_GENERADO]';
```

**Resultado esperado:**
- [ ] ✓ Orden insertada en `aocr_or_orden`
- [ ] ✓ Detalle insertado en `aocr_or_orden_detalle`
- [ ] ✓ `codigo_usuario` y `codigo_solicitud` son INTEGER
- [ ] ✓ `total` = suma de `total_linea` de detalles
- [ ] ✓ NO hay columnas inexistentes (observacion, subtotal, admin, etc.)
