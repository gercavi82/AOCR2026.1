# Root Cause Analysis - Órdenes de Recaudación AOCR

**Fecha:** 5 de enero de 2026  
**Analista:** Sistema  
**Prioridad:** P0 - Crítico

## Problema Principal

Error 42P01 al navegar a `SolicitudAOCR?abrir=nueva`:
```
Npgsql.PostgresException: 42P01: relation "aocr_tbhistorialestado" does not exist
```

## Causa Raíz

### 1. Tabla Faltante (P0)
- **Tabla:** `aocr_tbhistorialestado`
- **Impacto:** Bloquea completamente el flujo de creación de solicitudes
- **Referencias:** `HistorialEstadoDAO.cs`, `SolicitudBL.cs`
- **Solución:** Crear tabla con script SQL `01_crear_tabla_historial_estado.sql`

### 2. Columnas Inexistentes en aocr_or_orden (P0)
- **Columnas usadas en código pero NO en BD:** observacion, subtotal, admin, lugar_emision, correo, telefono, concepto_id
- **Archivos afectados:** `OrdenRecaudacionDAO.cs` líneas 263-312, 399-413, 601-620
- **Error producido:** `42703: column "observacion" does not exist`
- **Solución:** Ajustar SQL a columnas reales (8 columnas)

### 3. Columnas Inexistentes en aocr_or_orden_detalle (P0)
- **Columnas usadas en código pero NO en BD:** concepto_codigo, descripcion, porcentaje_admin, subtotal, admin
- **Archivos afectados:** `OrdenRecaudacionDAO.cs` líneas 363-382, 650-657
- **Solución:** Usar solo columnas existentes (7 columnas)

### 4. Columnas Inexistentes en aocr_tbsolicitud (P0)
- **Columnas usadas en código pero NO en BD:** tipo_solicitud, ciudad, provincia, pais, codigo_tecnico, created_at, updated_at, deleted_at
- **Archivos afectados:** `SolicitudDAO.cs:23-31`, `SolicitudAOCRDAO.cs:100-117`
- **Solución:** Eliminar referencias o migrar BD

### 5. Tipos Inconsistentes (P1)
- **Problema:** `CodigoUsuario`/`CodigoSolicitud` son INTEGER en BD pero string en C#
- **Riesgo:** Conversión manual puede guardar NULL silencioso
- **Archivos:** `OrdenRecaudacion.cs:27-33`
- **Solución:** Cambiar a int? en entidad

### 6. Sintaxis JavaScript (P2)
- **Error:** Cierre extra `};` en línea 946-948
- **Error:** Operador `?.` no soportado en C# 5
- **Impacto:** "Unexpected token '}'" y CS8026
- **Solución:** Eliminar `};` extra y reemplazar `?.` con ternarios
